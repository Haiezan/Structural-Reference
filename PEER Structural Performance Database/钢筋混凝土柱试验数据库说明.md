# PEER 钢筋混凝土柱结构性能数据库说明

## 1. 数据来源

本目录保存的是 PEER Structural Performance Database 中的钢筋混凝土柱试验数据。

- 原始网站：https://nisee.berkeley.edu/spd/index.html
- 数据库名称：PEER Structural Performance Database
- 数据主题：钢筋混凝土柱在循环侧向荷载作用下的结构性能试验
- 下载日期：2026-06-06

原网站说明该数据库汇集了 400 余个钢筋混凝土柱循环侧向加载试验结果，主要包括：

- 矩形钢筋混凝土柱；
- 螺旋筋或圆箍筋约束柱；
- 含搭接或不含搭接的柱；
- 不同轴压比、剪跨比、纵筋率、横向约束形式和破坏类型的试件。

数据库面向地震工程与钢筋混凝土构件抗震性能研究，可用于柱构件滞回性能、破坏模式、延性、刚度退化、承载力退化、轴压影响和横向约束效果等分析。

## 4. 属性表说明

属性表位于：

```text
properties/
├── rectangular_properties.txt
└── spiral_properties.txt
```

这两个文件均为制表符分隔文本文件，第一行为字段名，后续每行为一个试件记录。

### 4.1 矩形柱属性表

文件：

```text
properties/rectangular_properties.txt
```

记录数：253 条。

主要字段包括：

| 字段类别 | 示例字段 |
|---|---|
| 基本信息 | `No.`, `Specimen Name`, `Comments` |
| 材料性能 | `f'c (MPa)`, `fyl corner (MPa)`, `fyt (MPa)`, `fsu Trans` |
| 几何尺寸 | `B (mm)`, `H (mm)`, `L (mm)`, `Lsplice (mm)` |
| 加载信息 | `Axial Load (kN)`, `P-D`, `Config.` |
| 纵向钢筋 | `Diameter Corner (mm)`, `Diameter Interm (mm)`, `Total # Bars`, `Reinf Ratio` |
| 横向钢筋 | `Type of confinement`, `Confinement code`, `Nv`, `Spacing (mm)`, `Vol Trans Reinf Ratio` |
| 破坏结果 | `Failure`, `Ltop`, `Lbottom`, `Lbeam`, `Lmeasured (mm)` |

常见单位：

- 混凝土强度：MPa；
- 钢筋屈服强度和极限强度：MPa；
- 轴力：kN；
- 长度、截面尺寸、钢筋直径和间距：mm；
- 配筋率：无量纲比值。

### 4.2 螺旋/圆箍柱属性表


记录数：163 条。

主要字段包括：

| 字段类别 | 示例字段 |
|---|---|
| 基本信息 | `No.`, `Specimen Name`, `Comments` |
| 截面信息 | `Diameter`, `Cross Section`, `Cover to Ctr of Hoop Bar` |
| 材料性能 | `f'c`, `fy Long Bars`, `fsu Long Bars`, `fy, Spiral` |
| 几何尺寸 | `Length`, `Lsplice`, `Lmeasured`, `Lbeam`, `Lbottom` |
| 纵向钢筋 | `# Longitudinal Bars`, `Diameter Long Bars`, `rho Long` |
| 螺旋/箍筋 | `Hoop Spacing, sv`, `Diameter, Spiral`, `rho Spiral` |
| 加载与结果 | `Configuration`, `P`, `P-D`, `Failure Type` |

其中 `Cross Section` 的常见取值包括：

- `C`：圆形截面；
- `O`：八边形截面；
- `S`：方形截面。

## 5. 单条记录详情

每条试验记录均保存为两种格式：

```text
records_xml/001.xml
records_html/001.html
```

文件名中的三位编号对应数据库中的试验编号。例如：

- `001.xml` 和 `001.html` 对应 `PEER-SPD-1`；
- `416.xml` 和 `416.html` 对应 `PEER-SPD-416`。

建议优先使用 XML 文件进行程序化处理，因为 XML 中字段结构更清晰，包含材料、几何、加载、配筋、破坏和资源链接等信息。

典型 XML 结构包括：

```text
columnTests
└── columnTest
    ├── specimen
    ├── adminInfo
    ├── materialProperties
    ├── geometry
    ├── loading
    ├── longitudinalReinforcement
    ├── transverseReinforcement
    ├── failureType
    ├── damage
    └── links
```

其中：

- `specimen`：试件名称、类型、注释和参考文献；
- `materialProperties`：混凝土和钢筋材料性能；
- `geometry`：截面尺寸、等效悬臂长度、实测长度、搭接长度和试验构型；
- `loading`：轴力、P-Delta 修正方式等；
- `longitudinalReinforcement`：纵向钢筋直径、数量、保护层和纵筋率；
- `transverseReinforcement`：箍筋或螺旋筋形式、间距、直径和体积配箍率；
- `damage`：混凝土压碎、剥落、纵筋屈曲、纵筋断裂、螺旋筋断裂和轴压承载力丧失等损伤观测；
- `links`：力-位移数据、图表、照片、报告或外部网站链接。

## 6. 力-位移数据

力-位移数据和其他可下载资源保存在：

```text
force_displacement_data/
```

本次共成功下载 414 个 `data` 类型资源。原网站说明力-位移文件格式如下：

1. 第一行为试验名称；
2. 第二行为力-位移数据点数量；
3. 第三行起为成对数据；
4. 第一列通常为柱顶位移，单位为 mm；
5. 第二列通常为侧向力，单位为 kN；
6. 数据统一按等效悬臂柱形式报告，即使原始试验构型并非标准悬臂柱。

文件名已在下载时添加试验编号前缀，例如：

```text
001_gill79s1.txt
```

其中 `001` 对应数据库记录编号，后面的名称来自原始链接文件名。

## 8. 建议使用方式

### 8.1 快速查看总体属性

如果只需要构件参数和试验结果，优先使用：

```text
properties/rectangular_properties.txt
properties/spiral_properties.txt
```

这两个文件适合导入 Excel、Python pandas、MATLAB 或数据库系统。

### 8.2 获取单条记录的完整信息

如果需要参考文献、损伤观测、资源链接和更结构化的字段，建议读取：

```text
records_xml/
```

XML 文件比属性表更适合做精细化数据抽取。

### 8.3 分析滞回曲线

如果需要分析滞回性能、骨架曲线、刚度退化或耗能能力，可使用：

```text
force_displacement_data/
```

建议处理流程：

1. 通过属性表或 XML 确定目标试件编号；
2. 在 `resource_links.csv` 中查找该编号对应的 `data` 类型资源；
3. 读取 `force_displacement_data/` 中相应文件；
4. 按位移和侧向力两列绘制滞回曲线；
5. 与轴压比、剪跨比、配筋率、约束形式和破坏模式等字段联合分析。

## 9. 数据质量与注意事项

使用该数据库时应注意以下问题：

1. 原始数据来自不同研究者和不同年代的试验报告，字段完整性可能不一致。
2. 部分记录中的材料强度、保护层、构件长度或 P-Delta 信息可能有注释说明，使用前应查看 `Comments` 字段。
3. 个别记录可能缺少力-位移数据，但仍保留属性和试验说明。
4. 破坏类型编码通常包括：
   - `1`：弯曲破坏；
   - `2`：剪切破坏；
   - `3`：弯剪破坏。
5. 不同试验构型已按等效悬臂柱形式整理，但进行严格力学对比时仍应关注原始 `Configuration`、`Lmeasured`、`Lbeam`、`Ltop` 和 `Lbottom` 等字段。
6. 逗号可能出现在部分数值文本中，例如 `1,200`，程序读取时需要先清理千位分隔符。
7. 属性表为制表符分隔格式，不能简单按逗号解析。
8. XML 文件声明编码为 `ISO-8859-1`，批处理时应注意编码兼容。

## 10. 适合的研究用途

该数据集可支持以下工作：

- 钢筋混凝土柱抗震性能统计分析；
- 轴压比对柱延性和破坏模式影响研究；
- 剪跨比对弯曲、剪切和弯剪破坏转换的影响研究；
- 横向约束形式和体积配箍率对延性能力的影响研究；
- 滞回曲线、骨架曲线和耗能能力提取；
- 经验模型或机器学习模型训练；
- 数值模拟模型校准；
- 结构抗震性能数据库构建与二次整理。

## 11. 引用建议

使用本地数据时，应优先引用原始试验报告。每条 XML 记录中的 `reference` 字段给出了该试件对应的原始文献。

同时可说明数据整理来源为：

```text
PEER Structural Performance Database
https://nisee.berkeley.edu/spd/index.html
```

如果分析使用了具体试件，应在论文、报告或数据说明中列出对应试件编号、试件名称和原始参考文献。
